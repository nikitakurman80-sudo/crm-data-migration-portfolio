
# CRM Data Migration & SQL Validation

**Portfolio Project | Mykyta Kurman**

## Project Overview

This project simulates a CRM data migration from a legacy system to a new SaaS platform.

The objective is to analyze, clean, map, migrate, and validate 1,000 synthetic customer records.
